Project Objective

I find my moodboards tend to fall apart as they grow. Patterns blur, and it’s hard to pinpoint what actually connects the images. Instead of using computer vision to put things into rigid boxes, I wanted to build a tool to help sort through the chaos while keeping the creative process playful.

Project Overview

Clustr is a prototype that uses two computer vision models (CLIP and DINO) to organize messy image collections. Images are sorted into loose clusters based on either subject matter or visual style. Groups are labelled automatically using their nearest distinctive keywords within the Unsplash dataset.

2 / Key Design Decisions

A Dial, Not a Category

Placeholder copy. Rather than forcing each image into one fixed bucket, clustr exposes a semantic ↔ aesthetic slider that blends two models — CLIP for subject matter and DINO for visual style. Dragging the slider re-sorts the whole board in real time, so the user decides what "alike" means instead of the tool deciding for them.

Loose Clusters Over Rigid Boxes

Placeholder copy. Groupings are deliberately soft — a UMAP layout with light clustering on top — so images drift toward neighbors rather than snapping into hard partitions. The goal is to reveal a direction that is already hiding in the pile, not to impose a taxonomy.

Labels That Move With the Slider

Placeholder copy. Each cluster names itself from its nearest distinctive keywords, drawn from a subject vocabulary and a style vocabulary that are weighted by the slider. As the board shifts from subject to style, the labels shift with it — from nouns to aesthetic terms.

Everything in the Browser

Placeholder copy. Both models run client-side, so the tool is private, free, and instantly shareable — no accounts, no uploads, no server to keep alive.
