Project Objective

Clustr was built to explore a more playful way of making sense of visual clutter. Moodboards tend to get messy quickly, making it difficult to verbalize emerging directions. This project explores how computer vision can serve as a lightweight creative assistant, sorting raw inspiration to make implicit aesthetic patterns visible. The goal was to see if machine learning could handle the initial taxonomy while keeping the sorting experience tactile and fun.

Project Overview

Clustr is an experimental prototype that uses computer vision models (CLIP and DINO) to organize uncurated image collections. Users drop in a scattered batch of inspiration, and the interface automatically slides related images into aesthetic groups to reveal the themes hiding across the board.
